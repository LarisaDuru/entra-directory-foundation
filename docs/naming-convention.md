# Naming convention

## Security Group Convention: 
I used the security group naming convention
SEC-<Type>-<Name>

## Northwind service Department Groups:
- SEC-Dept-Executive 
-	SEC-Dept-IT 
-	SEC-Dept-Finance 
-	SEC-Dept-Sales 
-	SEC-Dept-HR 
-	SEC-Dept-Contractors
-	
Role Groups:
Role-based groups use the same structure like SEC-Role-Helpdesk
User Naming:
User accounts follow: firstname.lastname@companiesemail.tenant.onmicrosoft.com
